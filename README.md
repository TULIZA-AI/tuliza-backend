## What This Is

Tuliza AI is a clinical decision-support API that helps Community Health
Volunteers (CHVs) navigate early pregnancy loss care in low-resource settings.
It combines a trained ML classifier with a multilingual NLP layer to assess
risk, route women to equipped facilities, and provide culturally sensitive
aftercare guidance.

**Model performance:**
| Metric | Value |
|--------|-------|
| ROC-AUC | 0.937 |
| Recall (formal care class) | 88.9% |
| F1-Score | 0.889 |
| Accuracy | 91.0% |
| Cross-validation AUC | 0.737 ± 0.05 |

## Quick Start

### Prerequisites
- Python 3.11+
- pip
- The model files: `triage_pipeline.pkl` and `model_meta.pkl`

### 1. Clone the repository

```bash
git clone https://github.com/TULIZA-AI/tuliza-backend.git
cd tuliza-backend
```

### 2. Create and activate virtual environment

```bash
python3 -m venv venv

# Linux / macOS
source venv/bin/activate

# Windows
venv\Scripts\activate
```

### 3. Install dependencies

```bash
cd backend
pip install -r requirements.txt
```

> **Note:** First install downloads the NLP model (~250MB) on first API request.
> This happens once and is cached automatically.

### 4. Add model files

Place the following files in `backend/tuliza_model/`:

```
backend/
└── tuliza_model/
    ├── triage_pipeline.pkl   ← trained Random Forest pipeline
    └── model_meta.pkl        ← model metadata (AUC, features, etc.)
```

These files are generated by the training notebook. Contact the team or
download from the shared drive if you do not have them.

### 5. Start the server

```bash
cd backend
uvicorn main:app --reload --port 8000
```

The API is now running at:
- **API root:** http://localhost:8000
- **Interactive docs:** http://localhost:8000/docs
- **Health check:** http://localhost:8000/health

## API Endpoints

### POST `/api/triage/assess`
Assess care-seeking risk for a pregnancy loss case.

```json
{
  "type_of_loss": "Miscarriage",
  "gestational_age": 3.0,
  "place_of_loss": "Within same DSA Slum",
  "slum_resident": "Slum"
}
```

Response:
```json
{
  "risk_score": 0.72,
  "risk_level": "HIGH",
  "risk_percent": 72,
  "seek_formal_care": true,
  "message": "This woman is at high risk...",
  "action": "REFER_NOW",
  "next_step": "Contact the nearest health facility immediately."
}
```

### POST `/api/nlp/symptom-triage`
Analyse free-text symptom description in English or Swahili.

```json
{
  "text": "ana damu nyingi na homa kali sana leo",
  "language": "sw"
}
```

Response:
```json
{
  "urgency": "HIGH",
  "confidence": 0.89,
  "symptoms_detected": [
    { "term": "damu nyingi", "flag": "HIGH", "clinical": "Haemorrhage (SW)" },
    { "term": "homa", "flag": "HIGH", "clinical": "Fever (SW)" }
  ],
  "recommendation": "Immediate referral required. Use the Facility Finder now."
}
```

### POST `/api/facilities/find`
Get ranked nearby facilities based on risk level and location.

```json
{
  "location": "Within same DSA Slum",
  "risk_level": "HIGH",
  "slum_context": true
}
```

### POST `/api/aftercare/support`
Get personalised aftercare guidance in English or Kiswahili.

```json
{
  "loss_type": "Miscarriage",
  "gestational_age": 3.0,
  "risk_level": "HIGH",
  "language": "sw"
}
```

├── backend/
│   ├── main.py                    # FastAPI app, CORS, router registration

## Deployment

### Local (development)
```bash
uvicorn main:app --reload --port 8000
```

### Production (Render.com)
1. Push to GitHub
2. Go to [render.com](https://render.com) → New → Web Service
3. Connect the `tuliza-backend` repository
4. Render auto-detects `render.yaml` and deploys

Environment variables required:
```
PYTHON_VERSION=3.11.0
```

Training data is sourced from the **APHRC DASSA platform** under the
AI for Reproductive Health in Africa Innovation Challenge data licence.

Key datasets:
- `lostpregnancies_ANON.csv` — 211 early pregnancy loss events (primary)
- `Women_ANON.csv` — 1,956 women (demographic context)

Data is not included in this repository. Access via
[dassa.aphrc.org](https://dassa.aphrc.org).
